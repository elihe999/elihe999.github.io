架构解读#

网关层#

所有外部请求通过 API Gateway 统一入口，完成路由分发与鉴权校验后，按业务线转发至对应服务。

业务服务层#

  • User Service：用户注册、登录、权限管理等核心功能
  • Notification Service：邮件、短信、站内信等通知推送

业务服务之间通过 Kafka 消息总线实现异步解耦——用户服务发布事件，通知服务消费事件。

数据中台层#

数据中台是整条数据价值链的核心，按职责分为四个子域：

子域 职责
数据接入 从异构数据源（日志、DB、API）抽取原始数据
数据建模 将原始数据标准化、清洗、建模
数据资产 元数据管理、数据目录、数据血缘
数据服务 对外提供统一数据 API，支持实时/批量推送

基础设施层#

  • PostgreSQL：持久化存储，承载业务数据与建模后的标准数据
  • Kafka：异步事件总线，实现服务间松耦合通信
